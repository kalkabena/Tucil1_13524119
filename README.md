# Tucil1_13524119
Proyek membuat program yang menyelesaikan masalah queens linkedin dengan parameter yang diinput melalui file menggunakan algoritma brute force dan menulis hasilnya ke file.

Requirement: C++ ver. 11+

kompilasi: g++ main.c queens.c

Cara menjalankan:
1. Jalankan program
2. Masukkan path ke file input ynag valid
3. Tunggu hingga algoritma selesai
4. Pilih apakah menulis output ke file atau tidak
